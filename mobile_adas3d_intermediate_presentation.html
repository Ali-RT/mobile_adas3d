13 / 18
Engineering optimization

Vectorized decode removed CUDA synchronization overhead

Old decoder

  • looped over candidates in Python
  • used repeated .item() calls
  • caused GPU→CPU synchronization
  • decode mean: 15.84 ms

Vectorized decoder

  • gathers candidate tensors in batch
  • moves compact results to CPU once
  • uses class-aware NMS
  • decode mean: 2.54 ms
Biggest lesson: deployment bottlenecks are not always in the neural network.
