MobileADAS3D: Building and Benchmarking a Lightweight Monocular 3D Detector for ADAS

**3. Short one-sentence description**

This project builds a compact monocular 3D object detection pipeline that uses a single camera image to detect cars, pedestrians, and cyclists and estimate their 2D location, depth, 3D size, and orientation for ADAS-style scene understanding.
